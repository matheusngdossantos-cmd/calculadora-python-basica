## 🎯 Estrutura do Projeto
O projeto contém 3 implementações com evolução didática:
1. `calculadora_simples.py`: Estrutura sequencial com `input()`, conversão de tipos com `float()`, desvio condicional (`if/elif/else`) e proteção contra divisão por zero.
2. `calculadora_funcoes.py`: Arquitetura modular com funções (`def somar()`, `def subtrair()`, etc.).
3. `calculadora_completa.py`: Loop contínuo com `while True` e tratamento de erros com `try/except ValueError`.

---

## 💡 Principais Aprendizados:
- Como coletar e converter entradas do usuário (`str` para `float`).
- A diferença entre concatenação de strings (`"10" + "5" = "105"`) e soma matemática (`15.0`).
- Formatação de texto com f-strings (`:.2f`).
- Prevenção ativa do erro `ZeroDivisionError`.
- Código limpo e indentação seguindo as convenções da **PEP 8**.
